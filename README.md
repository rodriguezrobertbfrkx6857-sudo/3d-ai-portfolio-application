# 3D / Interactive Media AI Specialist Application Package

This folder contains the application-facing resume files and final evidence
report for a verified Godot portfolio set. The three projects are separate
GitHub repositories so each claim can be traced to source, screenshots, and a
runnable scene.

## Included

- [`resume/Resume_EN.md`](resume/Resume_EN.md) - English one-page-first resume source.
- [`resume/Resume_CN.md`](resume/Resume_CN.md) - Chinese one-page-first resume source.
- [`resume/Resume_EN.pdf`](resume/Resume_EN.pdf) - rendered English resume.
- [`resume/Resume_CN.pdf`](resume/Resume_CN.pdf) - rendered Chinese resume.
- [`FINAL_3D_PORTFOLIO_REPORT.md`](FINAL_3D_PORTFOLIO_REPORT.md) - requirement mapping, QA status, and honesty audit.

## Scope and honesty boundary

The package describes independent portfolio projects built for this
application. It does not invent employment history, client work, awards,
seniority, years of experience, Blender/Maya/3ds Max expertise, or any other
claim that is not visible in the linked repositories.
